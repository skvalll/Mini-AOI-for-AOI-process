# Mini AOI for PCB Inspection

This project is a graduation project that develops a basic AOI (Automated Optical Inspection) system for detecting missing components on printed circuit boards (PCBs).

The system uses a webcam to capture PCB images and OpenCV for image processing. Fixed Regions of Interest (ROIs) are used to inspect the expected positions of components and determine whether the components are present or missing.

## Main Features

- Capture PCB images using a webcam
- Define fixed ROIs for component inspection
- Process images using OpenCV
- Detect missing components
- Display inspection results
- Export inspection results to CSV files

## Technologies

- Python
- OpenCV
- NumPy
- Webcam

## Project Purpose

The system is developed as a basic and low-cost AOI solution for academic purposes. It can be used to study image processing techniques and the basic principles of automated PCB inspection.

## Project Status

This project was developed as a graduation project and is intended for academic and experimental purposes.
